# KiNO!BERNIC

Версия KinoLab для портативных приставок Anbernic. Только онлайн-поток, без
торрентов.

Проверено на двух приставках:

| Приставка | Система | Экран | Python |
|---|---|---|---|
| RG34XX SP | muOS `2601.0_JACARANDA` | 720×480 | 3.11.8 |
| RG35XX H | стоковая прошивка (модифицированная) | 640×480 | 3.10.12 |

Раскладка считается от фактического размера экрана, так что 640×480 (RG35XX,
RG40XX, RG28XX) и 720×720 (RG CubeXX) обсчитываются тоже — но живьём эти
модели не проверялись.

## Как устроено

Компилятора на приставке нет, pygame тоже нет, зато есть Python и SDL2 2.28 с
ttf и image. Поэтому всё написано на Python поверх SDL2 через `ctypes` —
собирать нечего, файлы просто копируются на карту.

| Файл | Что делает |
|---|---|
| `app.py` | экраны, навигация, цикл событий |
| `sdl.py` | обвязка SDL2/SDL2_ttf/SDL2_image через ctypes |
| `layout.py` | метрики под разные экраны линейки |
| `gamepad.py` | evdev: кнопки и крестовина |
| `player.py` | запуск mpv и управление им по IPC |
| `osd.py` | своя графика поверх видео (подсказки, меню серий) |
| `resolve.py` | Veoveo и Collaps: серии, озвучки, выбор видеопотока |
| `search.py` | поиск по названию |
| `catalog_sync.py` | сборка «Главной», подборок, обложек и баннеров на карту |
| `qr.py`, `android.py` | ссылка на APK андроид-версии кодом на экране |
| `device.py`, `battery.py` | модель приставки и заряд |
| `voices.py` | сезоны, серии и озвучки: общее правило для каталога и плеера |
| `account.py`, `pair.py` | аккаунт KinoLab и привязка приставки |
| `update.py` | проверка и установка обновлений |
| `control.py` | сокет управления для отладки |

## Установка

**muOS.** Положить `.muxapp` из релиза в `ARCHIVE` на карте и поставить через
Archive Manager. Или вручную: содержимое папки из архива — в
`MUOS/application/KiNO!BERNIC/`. Запуск: **Applications → KiNO!BERNIC**.

**Стоковая прошивка.** Скрипт `KiNO!BERNIC.sh` — в `Roms/APPS/`, код — в
`Roms/APPS/kinobernic/`, иконку — в `Roms/APPS/Imgs/`. Запуск из раздела
приложений.

Каталог собирается один раз на самой приставке:

    python3 catalog_sync.py

## Обновления

Приложение читает манифест `update.json` по списку адресов (первый ответивший
выигрывает — GitHub открывается не у всех), качает `.muxapp`, проверяет его и
выходит с кодом 36. Разворачивает архив запускалка, когда python уже закрыт:
менять файлы работающего приложения — плохая идея.

## Аккаунт

Вход по нику или почте на вкладке «Профиль»; регистрации на приставке нет —
подтверждать почту нечем, аккаунт заводится в приложении для телефона.

Списки общие с телефоном и ноутбуком в обе стороны: «Продолжить», «Избранное»
и «Вы смотрели». Приставка не только читает их, но и пополняет — позиция
просмотра пишется по ходу дела, досмотренное снимается у всех устройств
сразу. Правила одинаковые со всеми клиентами, иначе списки расходятся:
отметка живёт с пятой секунды, вернуться предлагаем с десятой, досмотренным
считается просмотр после минуты, дальше 95 % или последние три минуты.

Без сети и без аккаунта продолжение тоже работает — отметки лежат на карте
в `positions.json`.

## Стенд: приставка на настольной машине

Приложение запускается на компьютере — тот же код из `app/`, подменяется
только железо: клавиатура вместо `/dev/input`, заглушка заряда, TCP вместо
unix-сокета.

    python stand/setup.py                  # один раз: библиотеки SDL и шрифты
    python stand/run_stand.py --screen 640x480

Подробности и раскладка клавиш — `stand/README.md`. Стенд не заменяет
проверку на приборе: настоящие коды кнопок, фреймбуфер, скорость A53, звук и
установку обновления он не проверяет.

## Проверки

Работают без приставки и без сети:

    python tests/run_all.py         все разом

    python tests/test_voices.py     сезоны, серии, озвучки
    python tests/test_resolve.py    разбор мастер-плейлиста и Collaps
    python tests/test_marks.py      правила просмотра и отметки
    python tests/test_account.py    ключи записей и разбор синхронизации
    python tests/test_update.py     версии, манифест, годность архива, поиск
    python tests/test_layout.py     раскладка на всей линейке экранов

## Сборка релиза

Байткод привязан к версии интерпретатора, поэтому архив собирается на каждой
приставке, а наборы складываются в один файл:

    python3 tools/build_release.py --app app --out dist --version 0.3.0

В `dist/bundles` копятся `app-310.pyz`, `app-311.pyz` и так далее; запускалка
выбирает свой по `sys.version_info`. Собирать нужно тем же Python, что стоит на
целевой приставке — чужой `.pyc` не читается вовсе.

## Управление

| Кнопка | Каталог | Плеер |
|---|---|---|
| крестовина | навигация | перемотка ← → на 30 секунд |
| A | открыть / выбрать | пауза |
| B | назад / выход | выход (с подтверждением) |
| Y | — | сезоны, серии и озвучки |
| B (во время ожидания) | отменить поиск потока или синхронизацию | — |
| L1 R1 | вкладки | скрыть подсказки |
| START | поиск | — |

Коды кнопок сняты нажатиями на обеих приставках и совпадают: A 304, B 305,
X 307, Y 306, L1 308, R1 309, SELECT 310, START 311.
